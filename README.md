# Watchmen Security and Training

Responsive React, Vite, and TypeScript prototype for the first Watchmen marketing-site release.

## Run locally

```powershell
npm install
npm run dev
```

Before sharing changes, run:

```powershell
npm run lint
npm run build
```

## Prototype boundaries

- The inquiry form validates in the browser but does not submit anywhere yet.
- The production Square booking URL, contact details, course logistics, pricing, and schedules are still required.
- Instructor credentials and agency references must be verified and approved before publication.
- The portrait block is intentionally a placeholder until an approved image and usage rights are supplied.

See `docs/CURSOR_AGENT_ROADMAP.md` for the guided plan to finish the site with Cursor agents.
